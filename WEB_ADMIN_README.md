# Веб-панель администратора

Веб-интерфейс для управления ботом Quill Studio.

## 🚀 Запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите веб-сервер:
```bash
python run_web_admin.py
```

Или используйте uvicorn напрямую:
```bash
uvicorn web_admin.main:app --host YOUR_SERVER_IP --port 8000
```

3. Откройте в браузере:
```
http://localhost:8000
```

## 🔐 Вход

1. Откройте страницу входа
2. Введите ваш Telegram ID (можно узнать у бота @userinfobot)
3. Убедитесь, что у вас есть роль Admin в боте

## 📋 Функционал

### Главная панель
- Статистика: общее количество пользователей, активных заданий, заявок на вывод
- Быстрые действия для перехода к основным разделам

### Управление заданиями
- Просмотр всех активных заданий
- Добавление новых заданий:
  - Канал (username)
  - Сумма вознаграждения
  - Количество нужных подписчиков

### Пользователи
- Полный список всех пользователей
- Информация о каждом пользователе:
  - ID, имя, username
  - Номер телефона
  - Балансы (верифицированный/неверифицированный)
  - Количество рефералов
  - Дата регистрации
- Поиск по имени, username, ID или телефону
- Переход к переписке с пользователем

### Заявки на вывод
- Список всех ожидающих заявок
- Информация о пользователе и сумме
- Принятие заявок
- Переход к переписке с пользователем

### Переписка с пользователями
- Чат с любым пользователем
- Отправка сообщений (доставляются через Telegram бота)
- Автообновление сообщений каждые 3 секунды
- История переписки

## 🔧 Технические детали

- **Framework**: FastAPI
- **Аутентификация**: JWT токены
- **База данных**: SQLite (та же, что использует бот)
- **Интеграция**: Сообщения отправляются через Telegram бота

## ⚙️ Настройка

Порт по умолчанию: `8000`

Изменить порт можно в файле `run_web_admin.py`:
```python
uvicorn.run(app, host="YOUR_SERVER_IP", port=8000)  # Измените порт здесь
```

## 🔒 Безопасность

- Только пользователи с ролью Admin могут войти
- JWT токены с истечением через 8 часов
- Все запросы требуют авторизации
- Проверка прав доступа на каждом endpoint

## 📝 Примечания

- Веб-панель использует ту же базу данных, что и Telegram бот
- Сообщения из веб-панели отправляются пользователям через Telegram
- Для работы переписки бот должен быть запущен
