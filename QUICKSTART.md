# Быстрый старт

## 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 2. Настройка

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_бота
BOT_OWNERS=@ваш_username
```

**Как получить токен:**
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в `.env`

## 3. Запуск

```bash
python main.py
```

## 4. Первый запуск

1. Запустите бота командой `/start` в Telegram
2. Подтвердите номер телефона
3. Если ваш username указан в `BOT_OWNERS`, вам автоматически будет выдана роль Admin

## 5. Создание первого задания

1. Откройте "📊 Панель администратора"
2. Выберите "📢 Установить рекламу"
3. Отправьте ссылку на канал (например: `@channel` или `https://t.me/channel`)
4. Убедитесь, что бот добавлен в канал как администратор
5. Введите сумму вознаграждения
6. Введите количество нужных подписчиков

## ⚠️ Важно

- Бот должен быть администратором канала для проверки подписок
- Проверка подписок происходит автоматически каждые 24 часа
- Минимальная сумма вывода: $100 (настраивается в `config.py`)
