# 🚀 Быстрый старт Quill Studio Bot

## 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 2. Настройка

Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=токен_от_BotFather
OWNER_TELEGRAM_ID=ваш_telegram_id
BOT_OWNERS=@ваш_username
JWT_SECRET_KEY=случайная_длинная_строка
```

Сгенерировать JWT-ключ:
```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## 3. Запуск Telegram бота

```bash
python main.py
```

После запуска:
1. Откройте бота в Telegram
2. Отправьте команду `/start`
3. Подтвердите номер телефона
4. Вы автоматически получите роль Admin

## 4. Запуск веб-панели администратора

В новом терминале:

```bash
python run_web_admin.py
```

Затем откройте в браузере:
```
http://localhost:8000
```

Для входа используйте ваш Telegram ID из `.env` (`OWNER_TELEGRAM_ID`)

## 📋 Что дальше?

### В Telegram боте:
- Создайте задания через панель администратора
- Управляйте пользователями
- Обрабатывайте заявки на вывод

### В веб-панели:
- Добавляйте задания удобным интерфейсом
- Просматривайте всех пользователей с их данными
- Ведите переписку с пользователями
- Обрабатывайте заявки на вывод

## ⚠️ Важно

1. **Бот должен быть администратором канала** для проверки подписок
2. При создании задания убедитесь, что бот добавлен в канал как администратор
3. Веб-панель и бот используют одну базу данных

## 🔧 Если что-то не работает

1. Проверьте, что все зависимости установлены
2. Убедитесь, что порт 8000 свободен для веб-панели
3. Проверьте логи в консоли на наличие ошибок
