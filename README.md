# Telegram Бот для заработка на подписках

Бот для заработка пользователями на выполнении заданий (подписка на каналы) с системой верификации, реферальной программой и панелью администратора.

## 🚀 Возможности

### Для пользователей:
- ✅ Авторизация по номеру телефона
- 💰 Заработок на подписке на каналы
- 💸 Вывод средств (минимум $100)
- 🤝 Реферальная система
- 🆘 Поддержка и связь с администратором
- 📊 Профиль с балансами (верифицированный/неверифицированный)

### Для администраторов:
- 📢 Установка рекламы (заданий на подписку)
- 📨 Рассылка сообщений всем пользователям
- 💸 Управление заявками на вывод
- 🆘 Обработка тикетов поддержки
- 💬 Обработка запросов на связь
- 👥 Выдача роли Admin (только для владельцев)

### Система верификации:
- Автоматическая проверка подписок через 7 дней
- Перенос средств на верифицированный баланс при успешной верификации
- Списание средств при отписке раньше срока

## 📋 Требования

- Python 3.8+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🔧 Установка

1. Клонируйте репозиторий или скачайте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
BOT_TOKEN=your_bot_token_here
BOT_OWNERS=@your_username,@another_owner
```

4. Запустите бота:
```bash
python main.py
```

## ⚙️ Конфигурация

В файле `config.py` можно настроить:
- `MIN_WITHDRAWAL` - минимальная сумма вывода (по умолчанию $100)
- `SUBSCRIPTION_HOLD_DAYS` - количество дней удержания подписки (по умолчанию 7)
- `DB_PATH` - путь к базе данных SQLite

## 🗄️ База данных

Бот использует SQLite для хранения данных. База данных создается автоматически при первом запуске.

Таблицы:
- `users` - пользователи
- `tasks` - задания
- `user_tasks` - выполнение заданий пользователями
- `withdrawal_requests` - заявки на вывод
- `support_tickets` - тикеты поддержки
- `chat_requests` - привязка активной переписки пользователя с админом (поддержка)
- `chat_messages` - сообщения чатов (логирование)
- `logs` - логи действий

## 🔐 Владельцы бота

Владельцы указываются в `.env` файле через запятую:
```
BOT_OWNERS=@owner1,@owner2
```

Только владельцы могут выдавать роль Admin через панель администратора.

## 📝 Использование

### Для пользователей:

1. Запустите бота командой `/start`
2. Подтвердите номер телефона
3. Выберите "💰 Заработок" для просмотра заданий
4. Выполните задание (подпишитесь на канал)
5. Оставайтесь подписанным 7 дней для получения награды

### Для администраторов:

1. Получите роль Admin от владельца
2. Откройте "📊 Панель администратора"
3. Используйте "📢 Установить рекламу" для создания заданий
4. Используйте "📨 Сделать рассылку" для отправки сообщений

## ⚠️ Важные замечания

1. **Бот должен быть администратором канала** для проверки подписок
2. **Проверка подписок** происходит автоматически каждые 24 часа
3. **Все действия логируются** в базу данных
4. **Рефералы засчитываются** только после подтверждения номера телефона

## 🐛 Решение проблем

### Бот не отвечает:
- Проверьте правильность токена в `.env`
- Убедитесь, что бот запущен
- Проверьте логи на наличие ошибок

### Ошибки с базой данных:
- Убедитесь, что у бота есть права на запись в директорию
- Проверьте, что файл базы данных не заблокирован

### Проблемы с проверкой подписок:
- Убедитесь, что бот добавлен в канал как администратор
- Проверьте права бота в канале
